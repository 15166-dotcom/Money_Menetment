# สมุดงบรายเดือน 50/30/20

เว็บแอปแบ่งงบเงินเดือนแบบ 50/30/20 มีเฟสกองทุนฉุกเฉิน → ลงทุนระยะยาว
ไฟล์เดียว (`index.html`) ไม่มีเซิร์ฟเวอร์ ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องที่เปิด

## สำรองข้อมูล
ข้อมูลผูกกับเบราว์เซอร์ + โดเมนที่เปิด ย้ายโดเมนหรือล้างเบราว์เซอร์ = ข้อมูลไม่ตามมา
ใช้ ตั้งค่า → Export CSV ทุกสิ้นเดือน และ Import CSV เพื่อกู้คืน (รวมกับของเดิม ข้ามรายการซ้ำ)
